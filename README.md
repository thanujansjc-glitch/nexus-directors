# Nexus directors' view

A read-only, password-protected copy of the Nexus Finance Desk for the directors of Nexus Property Developers (Pvt) Ltd.

- `shell.html`: the password screen, plus a read-only stand-in for the app's data connection.
- `index.html`: shell.html with the current Finance Desk page inserted. Generated by build.py.
- `data.enc.json`: the full data snapshot, encrypted with AES-256-GCM using a PBKDF2-SHA256 key. It is unreadable without the password.
- `last_updated.txt`: the time of the snapshot.
- `build.py`: rebuilds index.html and data.enc.json. It runs each morning.
